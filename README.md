# Expense & Budget Visualizer

Aplikasi web sederhana untuk mencatat pengeluaran. Data disimpan secara lokal di browser pengguna.

## Fitur

- Tambah dan hapus transaksi dengan validasi input.
- Kategori bawaan dan kategori kustom yang tersimpan di browser.
- Total pengeluaran dan diagram distribusi kategori.
- Ringkasan bulanan: total, jumlah transaksi, dan kategori dengan pengeluaran terbesar.
- Pengurutan daftar berdasarkan transaksi terbaru, jumlah pengeluaran, atau kategori.

## Menjalankan tes

```bash
npm install
npm test
```
